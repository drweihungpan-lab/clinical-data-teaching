# SLN360 Phase 2 Clinical Trial Documents

This directory contains publicly available regulatory documents from the SLN360 Phase 2 clinical trial, used as teaching examples in clinical data analysis.

## Documents

- **SLN360_Phase2_Protocol.pdf** - The clinical trial protocol (Version 1.0)
- **SLN360_Phase2_StatisticalAnalysisPlan.pdf** - The statistical analysis plan (SAP Version 2.0)

## Study Details

- **Study ID**: NCT05537571 (SLN360-002)
- **Sponsor**: Silence Therapeutics
- **Indication**: Lipoprotein(a) Lowering
- **Study Status**: Completed
- **Enrolled Participants**: 180
- **Study Type**: Phase 2

## Source Documents

Regulatory documents are publicly available on [ClinicalTrials.gov](https://clinicaltrials.gov/study/NCT05537571):
- [Protocol](https://cdn.clinicaltrials.gov/large-docs/71/NCT05537571/Prot_000.pdf)
- [Statistical Analysis Plan](https://cdn.clinicaltrials.gov/large-docs/71/NCT05537571/SAP_001.pdf)

## Publication

  - [PubMed Link](https://pubmed.ncbi.nlm.nih.gov/39556769/)

## Use in Teaching

These documents serve as examples for:
- Understanding clinical trial protocols and structure
- Learning statistical analysis plan design and components
- Reviewing data management and safety considerations in clinical trials
