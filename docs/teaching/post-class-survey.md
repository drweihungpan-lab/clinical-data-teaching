# Post-class survey

**When:** end of session 3. **Time:** three to four minutes. **Use:** anonymous, ungraded feedback on the whole course. No names or personal/confidential examples required. Responses are not linked to the pre-class survey.

1. Rate your confidence from 1 (not confident) to 5 (very confident) in each item: explaining trial phases; distinguishing the four core roles; explaining the purpose of SDTM and TFLs; identifying what an early biomarker result cannot establish.
2. Which role most directly leads statistical design and the planned analysis? Select: biostatistician / data manager / QA / unsure.
3. If a scheduled lab value is missing, is replacing it with zero appropriate? Select: yes / no / unsure.
4. If a small early trial lowers a biomarker, has it necessarily established fewer clinical events? Select: yes / no / unsure.
5. Rate each from 1 (poor) to 5 (excellent): explanation clarity; relevance to statistics students; pacing; usefulness of examples.
6. Which professional handoff or concept is clearer now? Optional free text.
7. Which topic still needs clarification? Optional free text.
8. What should be shortened, expanded, or changed next time? Optional free text.

Instructor: compare distributions of the four repeated confidence items and three repeated knowledge items with the pre-class survey. Report response counts and missing responses. These unpaired convenience responses cannot establish individual gains or a causal teaching effect; confidence is not the same as knowledge. Use recurring comments to revise the next delivery.
