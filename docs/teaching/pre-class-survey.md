# Pre-class survey

**When:** before session 1. **Time:** about three minutes. **Use:** anonymous, ungraded group feedback. Do not request names, employer details, patient information, or examples from confidential work. A blank response is allowed.

1. How familiar are you with clinical trials? Select: no prior exposure / heard the basics / studied the topic / worked with clinical data.
2. Rate your confidence from 1 (not confident) to 5 (very confident) in each item: explaining trial phases; distinguishing the four core roles; explaining the purpose of SDTM and TFLs; identifying what an early biomarker result cannot establish.
3. Which role most directly leads statistical design and the planned analysis? Select: biostatistician / data manager / QA / unsure.
4. If a scheduled lab value is missing, is replacing it with zero appropriate? Select: yes / no / unsure.
5. If a small early trial lowers a biomarker, has it necessarily established fewer clinical events? Select: yes / no / unsure.
6. Which two topics most interest you? Choose up to two: trial design in practice / professional roles / clinical-data workflow / AI drug development / diagnostic evidence / privacy and governance / careers.
7. What one question would you like the course to answer? Optional free text.

Instructor: show only aggregate themes. Use item 1 to calibrate introductions and item 6 to choose which examples get extra explanation. Items 3–5 are baseline understanding checks, not a selection criterion. The [answer guide](answers.md#survey-key) is separate from this student-facing form.
