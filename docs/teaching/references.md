# Source register

Checked for this implementation on **2026-10-11**. Historical study findings are taught as dated findings, not statements about current authorization or pipeline status. Recheck official sources before a later delivery. Research notes contain more evidence than students need; use the concise slides in class.

| Topic | Primary source | Use |
| --- | --- | --- |
| Clinical-trial phases | [FDA definitions](https://www.fda.gov/drugs/investigational-new-drug-application-ind/drug-development-and-review-definitions) | Different questions and typical scale; not fixed sample-size rules |
| Preclinical replication (opening) | [Begley and Ellis, Nature, 2012](https://www.nature.com/articles/483531a) | One industry team's replication experience; not a universal rate. Checked 2026-11-25 |
| Preclinical development | [FDA preclinical research](https://www.fda.gov/patients/drug-development-process/step-2-preclinical-research), [ICH M3(R2)](https://database.ich.org/sites/default/files/M3_R2__Guideline.pdf) | What must be ready before first-in-human; two-species toxicity for typical small molecules. Checked 2026-11-25 |
| US permission to start a trial | [21 CFR 312.40](https://www.ecfr.gov/current/title-21/chapter-I/subchapter-D/part-312/subpart-B/section-312.40), [FDA IND overview](https://www.fda.gov/drugs/types-applications/investigational-new-drug-ind-application) | IND in effect 30 days after receipt unless clinical hold. Checked 2026-11-25 |
| EU permission to start a trial | [Clinical Trials Regulation (EU) 536/2014](https://eur-lex.europa.eu/eli/reg/2014/536/oj/eng) | Single application through CTIS; member-state assessment. Checked 2026-11-25 |
| Protocol/design | [FDA clinical research](https://www.fda.gov/patients/drug-development-process/step-3-clinical-research) | Link objectives, population, collection, and analysis |
| US drug review | [FDA review process](https://www.fda.gov/drugs/information-consumers-and-patients-drugs/fdas-drug-review-process-ensuring-drugs-are-safe-and-effective) | Medicine evidence and approval context |
| EU medicine authorization | [EMA authorization overview](https://www.ema.europa.eu/en/about-us/what-we-do/authorisation-medicines) | EMA assessment, Commission decision, national trial authorization |
| GCP and oversight | [ICH E6(R3) overview](https://admin.ich.org/sites/default/files/inline-files/ICH_E6%28R3%29_Step%204_Presentation_2025_0123.pdf) | Participant protection, reliable evidence, clear responsibilities |
| GCP context | [FDA E6(R3) guidance page](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/e6r3-good-clinical-practice-gcp) | Instructor reference; avoid treating guidance as identical law everywhere |
| SLN360 phase 1 | [Nissen et al., JAMA, 2022](https://jamanetwork.com/journals/jama/fullarticle/2790912) | Public study anchor; Table 1, Table 2, Figure 2 and supplements |
| Standardized data | [CDISC SDTM](https://www.cdisc.org/standards/foundational/sdtm) | Purpose of tabulation domains |
| Analysis-ready data | [CDISC ADaM](https://www.cdisc.org/standards/foundational/adam) | Analysis organization and traceability |
| Rentosertib discovery | [Ren et al., Nature Biotechnology, 2024](https://www.nature.com/articles/s41587-024-02143-0) | AI contribution to target/molecule work |
| Rentosertib clinical milestone | [Xu et al., Nature Medicine, 2025](https://www.nature.com/articles/s41591-025-03743-2) | Published phase 2a evidence, not proof of AI superiority |
| DSP-1181 discovery/entry | [Joint company announcement, 2020](https://www.sumitomo-pharma.com/news/20200130.html) | Sponsor-reported discovery timeline and phase I entry |
| DSP-1181 stop | [Sumitomo January 2022 presentation, slide 15](https://www.sumitomo-pharma.com/ir/library/presentation/assets/pdf/eir20220131.pdf) | Discontinued after unspecified expected criteria were unmet |
| Diagnostic performance | [IVDR](https://eur-lex.europa.eu/eli/reg/2017/746/oj/eng), [MDCG 2022-2](https://health.ec.europa.eu/system/files/2022-01/mdcg_2022-2_en.pdf) | Intended purpose and three performance-evidence components |
| Health-data processing | [GDPR](https://eur-lex.europa.eu/eli/reg/2016/679/oj/eng), [EDPB research response](https://www.edpb.europa.eu/sites/default/files/files/file1/edpb_replyec_questionnaireresearch_final.pdf) | Purpose, conditions, pseudonymization, research-consent distinction |
| ISMS | [ISO/IEC 27001 overview](https://www.iso.org/standard/27001) | Security risk management; no certification workshop |
| Product-data access | [Data Act](https://eur-lex.europa.eu/eli/reg/2023/2854/oj/eng), [Commission explanation](https://digital-strategy.ec.europa.eu/en/factpages/data-act-explained) | Conditional access rights and privacy interaction |
| EU medicine/device distinction | [EMA medical-device overview](https://www.ema.europa.eu/en/human-regulatory-overview/medical-devices) | EMA's defined device-related roles, not general device regulation |
